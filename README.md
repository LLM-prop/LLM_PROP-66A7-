# LLM_PROP

**Predicting Physical and Electronic Properties of Crystalline Solids from Their Text Descriptions**

## Problem Statement

Develop a lightweight language-model-based system that predicts crystal material properties from textual representations of crystal structures, and investigate whether carefully designed crystal-text representations can achieve competitive performance with substantially smaller models.

## Tech Stack

Python, PyTorch, Hugging Face Transformers, T5-small / BERT-small, pymatgen, scikit-learn, pandas, NumPy

## Reference

LLM-Prop paper: https://arxiv.org/abs/2310.14029
